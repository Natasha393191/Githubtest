# 📱 手機記帳App

一個簡單易用的手機記帳應用，幫助您輕鬆管理個人財務。

## ✨ 功能特色

### 基礎功能
- 💰 **收入支出記錄** - 快速記錄日常收入和支出
- 📊 **即時餘額顯示** - 清楚顯示總餘額、收入、支出統計
- 📝 **分類管理** - 預設常用分類，支出和收入分別管理
- 📅 **日期記錄** - 自動設定當前日期，可手動調整

### 進階功能
- 🔍 **篩選查詢** - 依月份、分類、類型篩選交易記錄
- 📈 **統計分析** - 月度收支統計和分類支出分析
- 💾 **本地儲存** - 所有資料保存在瀏覽器本地儲存
- 📱 **響應式設計** - 適配手機和平板設備

## 🚀 開始使用

1. 直接開啟 `index.html` 檔案
2. 點擊「收入」或「支出」按鈕開始記帳
3. 填寫金額、選擇分類、添加備註
4. 查看「歷史」頁面瀏覽所有記錄
5. 在「統計」頁面查看財務分析

## 🎨 頁面說明

### 首頁 (Home)
- 顯示總餘額、收入、支出統計
- 快速新增收入/支出按鈕
- 最近5筆交易記錄

### 記帳頁面 (Add)
- 收入/支出類型切換
- 金額輸入
- 分類選擇
- 備註說明
- 日期設定

### 歷史記錄 (History)
- 所有交易記錄列表
- 月份篩選
- 分類篩選
- 收入/支出類型篩選

### 統計分析 (Stats)
- 本月收支統計
- 支出分類統計圖表
- 餘額變化趨勢

## 🔧 技術特點

- **純前端實現** - 無需後端服務器
- **本地儲存** - 使用 localStorage 保存資料
- **響應式設計** - 適配各種螢幕尺寸
- **現代CSS** - 使用CSS變數和Flexbox/Grid布局
- **ES6語法** - 使用類別和現代JavaScript特性

## 🎯 使用建議

1. **定期記帳** - 建議每天記錄支出，養成良好習慣
2. **詳細分類** - 選擇合適的分類有助於分析消費習慣
3. **添加備註** - 重要支出可添加備註方便日後查詢
4. **定期檢視** - 每月查看統計分析，了解財務狀況
